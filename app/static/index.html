4-Context Grounding

Every response is synthesized from Category, Merchant, Trigger, and Customer context — zero hallucinations guaranteed.

🔄

Dynamic Versioning

Atomic context upgrades with version guards. Higher versions accepted, stale versions rejected, duplicates are idempotent.

🛡️

Suppression Engine

Suppression key deduplication + body-level fingerprinting ensures no customer receives the same message twice.

💬

Multi-Turn Memory

Up to 5 conversation turns tracked per session. Detects auto-reply loops, intent transitions, and off-topic deflections.

🎯

Intent State Machine

8-class intent classifier: Join, Yes, No/Stop, Tell Me More, Price Question, Busy/Later, Auto-Reply, Off-Topic.

📊

25+ Trigger Types

Covers all trigger kinds across Dentists, Salons, Restaurants, Gyms, and Pharmacies with context-accurate messaging.
